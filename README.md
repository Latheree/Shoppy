# Shoppy – Shop Website

A simple online shop for handmade home goods,its Name was Shoppy and built with plain HTML, CSS and JavaScript. No frameworks or installs needed.

## Features

- Product grid with 8 sample products
- Category filters (All, Ceramics, Textiles, Candles)
- Shopping cart that slides in from the side
- Change quantities and see the running total
- Cart is saved in the browser, so it stays after a refresh
- Works on phones and desktops, in light and dark mode
- Demo checkout (no real payment)

## How to run

1. Download or clone this repository.
2. Open `index.html` in any web browser.

## Live site

If GitHub Pages is on, the site is at:
`https://YOUR-USERNAME.github.io/latheree/`

To turn it on: **Settings → Pages → Branch: main → Save**.

## Customize

- **Products:** edit the `PRODUCTS` list in `index.html` (name, price, description, category).
- **Currency:** change the `CUR` value, for example `"$"` or `"₹"`.
- **Colors:** change the values under `:root` in the `<style>` section.
